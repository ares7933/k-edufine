# 공문 초안 작성기

학교 선생님이 제목과 내용을 입력하면 에듀파인 공문 서식(굴림체, 여백 3/1.5/2/1.5cm, 1. 가. 1) 가) 번호, 붙임·끝. 표시)에 맞춘 초안을 만들어 ODT 파일로 내려받는 웹페이지입니다.

- 바로 쓰기: https://ares7933.github.io/k-edufine/
- 서버 없이 브라우저 안에서만 동작하며, 입력한 내용과 학교 정보는 각자의 브라우저에만 저장됩니다.
